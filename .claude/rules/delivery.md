# Konventionen Umsetzungsplan

## Dateien
- `umsetzungsplan.md`

## Aufbau
```
# Umsetzungsplan – {Systemname}
## Vorgehen         → klassisch oder agil, mit Begründung (Stacey-Matrix)
## Releaseplan      → Tabelle: Release | Inhalt | Stories | Zeitraum | Meilenstein
## Risiken          → Tabelle: Risiko | Wirkung | Massnahme
## Entscheidungspunkte → Go/No-Go mit Kriterien
```
