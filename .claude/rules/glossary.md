# Konventionen Glossar

## Dateien
- `glossar.md` – eine Datei, alle Begriffe

## Aufbau
```
# Glossar – {Systemname}
## Überblick     → Ein Satz + Hinweis, dass Klassennamen auf die Entität verlinken
## A … Z         → ein H2 pro Anfangsbuchstabe; darunter eine Tabelle: Begriff | Bedeutung | Siehe
```

## Inhalt
- Jede Fachklasse hat einen Eintrag und verlinkt ihre Entitätsseite
- Abkürzungen ausgeschrieben (GLKB = Glarner Kantonalbank, MCP = Model Context Protocol)
- Ein neuer Begriff in einem Artefakt bekommt im selben Change Request einen Glossareintrag
