# Konventionen Validierung

## Dateien
- `validierung.md` – Validierungsgespräche mit Betroffenen
- `pocTest.md` – Test des PoC mit Beratenden (heute gegen neu)

## Aufbau
```
# Validierung – {Gegenstand}
## Ziel             → Welche Annahme oder Anforderung geprüft wird
## Vorgehen         → Teilnehmende, Methode, Termine
## Hypothesen / Fragen → nummeriert (H1, V1-F1 …)
## Ergebnisse       → Tabelle: Frage oder Hypothese | Ergebnis | Folge für die Anforderungen
## Änderungen an den Artefakten → Links auf die Change Requests, die aus der Validierung folgen
```

## Inhalt
- Ergebnisse stehen nur hier, wenn sie erhoben wurden; Ausstehendes ist als *ausstehend* markiert,
  nie geschätzt
- Jede Folge für die Anforderungen wird ein Change Request
